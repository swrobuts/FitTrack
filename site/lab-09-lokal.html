Lokale Modelle mit LM Studio

Alles, was im Kurs mit Claude im Chat entstanden ist, geht auch mit einem Modell auf dem eigenen Rechner: offline, ohne Abo, ohne dass Code das Haus verlässt. Der Preis ist Arbeitsspeicher und etwas Tempo. Die Demo stellt denselben Prompt an einen Coding-Spezialisten und einen Generalisten und lässt am Ende pytest entscheiden, nicht den Eindruck.

LM Studio Qwen3-Coder · Gemma Spezialist vs. Generalist Lokal vs. Cloud

Worum es geht

Der Workflow ist derselbe, nur der Anbieter wechselt.

Story, Test schlägt fehl, Prompt, Prüfen, Übernahme, Test besteht, Commit. Ob der Vorschlag von Claude, von Qwen3-Coder auf dem eigenen Laptop oder von einem anderen Modell kommt, ändert an der Prüfstelle nichts. Das ist auch der Plan B, wenn das Kontingent im Chat erschöpft ist.

Vorbereitung

Das große Modell vor der Veranstaltung herunterladen, im Raum dauert das zu lange. In LM Studio: Discover, nach „Qwen3 Coder 30B A3B“ suchen, Q4_K_M laden. Kontextlänge auf mindestens 8192 Token stellen, damit der Prompt mit Tests hineinpasst.

  5. Diskussion: Wann reicht lokal? Wann Cloud?

Worauf man achtet

Besteht der Code die Tests?

Die einzige Frage, die zählt. Zählt das Modell die leere Woche mit? Rundet es am Ende? Behandelt es die leere Liste?

Hält es die Randbedingungen?

Nur Standardbibliothek. Kleinere Modelle ignorieren Randbedingungen häufiger und bringen pandas mit.

Stimmt die Erklärung mit dem Code überein?

Die Erklärung klingt bei allen Modellen sicher. Ob sie stimmt, sieht man erst beim Lesen des Codes.

Stil

Generalisten formatieren schöner, Coding-Modelle halten sich enger an die Tests. Beides ist beobachtbar.

Anbindung an WebStorm

LM Studio stellt unter Developer → Start Server eine OpenAI-kompatible Schnittstelle bereit, meist unter http://localhost:1234/v1. Damit lässt sich der Editor anbinden: Das JetBrains-Plugin „Continue“ oder der JetBrains AI Assistant mit lokalem Modell bieten Autovervollständigung und Chat, vollständig lokal und kostenfrei. Für den Kurs bleibt der Chat-Weg der Standard, die Anbindung ist der Ausblick.

Übungen

Drei Übungen: lokal oder Cloud, die Demo vorbereiten, Ergebnisse bewerten.

Zusammenfassung

  • Derselbe Workflow, ein anderer Anbieter. Die Prüfstelle bleibt.
  • Coding-Spezialist gegen Generalist: gleicher Prompt, spürbar anderer Code. Das ist der Anlass, über Modellwahl zu sprechen.
  • Modelle vorab laden, Kontextlänge hochsetzen, den Prompt bereithalten.
  • Lokal, wo Datenschutz, Kosten oder Offline-Betrieb zählen. Cloud, wo Komplexität und Kontextlänge zählen.
  • Am Ende entscheidet pytest, nicht der Eindruck.
